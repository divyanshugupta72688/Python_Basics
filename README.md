# Python Basics

A collection of Python fundamentals covering core concepts, practiced topic-wise for learning and revision.

## 📂 Topics Covered

- **Variables** — Declaration, naming rules, dynamic typing
- **Datatypes** — int, float, str, bool, complex, and type checking
- **Type Casting** — Implicit and explicit conversions
- **Operators & Operands** — Arithmetic, comparison, logical, assignment, bitwise
- **Loops** — for, while, nested loops, break/continue
- **Strings** — Slicing, formatting, string methods
- **Lists** — Creation, indexing, slicing, list methods
- **Tuples** — Immutability, tuple operations
- **Sets** — Set operations, union, intersection, difference
- **Dictionaries** — Key-value pairs, dictionary methods

## 🛠️ Tech Stack

- Python 3.13
- PyCharm IDE

## 🚀 How to Run

```bash
python filename.py
```

Each topic has its own folder with example scripts to practice and reference.

## 📌 Purpose

This repository is maintained as a personal practice log while learning Python fundamentals, useful for quick revision before interviews and placement assessments.
